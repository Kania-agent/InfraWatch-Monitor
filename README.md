# InfraWatch-Monitor

**AI-Powered Infrastructure Monitoring Dashboard**

InfraWatch-Monitor is a comprehensive ops dashboard built with MiMo V2.5 intelligence. It provides real-time server monitoring with CPU/memory gauges, network metrics, and an intelligent alert panel to keep your infrastructure healthy.

## Features

- **Server Cards** — Real-time CPU and memory usage gauges for each server
- **Alert Panel** — Color-coded alerts with severity levels and timestamps
- **Network Metrics** — Live bandwidth and connection monitoring
- **Health Overview** — Service status indicators and uptime tracking

## Tech Stack

- Vanilla HTML/CSS/JavaScript
- No external dependencies
- Professional ops dashboard theme

## Getting Started

Open `index.html` in any modern browser to monitor your infrastructure.
